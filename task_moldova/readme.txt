Flag: SIGMOID_RHGLWQ

How I found it

Storks stay loyal to their nest, so every read of the same bird comes from the same place. I took all the white stork ring reads and grouped them by location.

Then, for each group, I looked for a registered stork living nearby. Almost every group had one, and its reads were just a messy version of that ring (look-alike letters mixed up, some letters unreadable). So those birds are already in the register.

One group had no registered stork anywhere near it: 24 reads around Cahul, in the Lower Prut area. The closest registered stork lives about 74 km away. That has to be the missing bird.

Its reads were noisy, but the noise doesn't agree with itself, while the true letters do. So at each of the six positions I took the letter seen most often, ignoring the "?" marks:

  R H G L W Q

The result stays the same if I count one vote per observer or one vote per day, so no single observer is steering it. And RHGLWQ is not in the register.
